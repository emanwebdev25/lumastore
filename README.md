# Luma Store 🛍️

Luma Store is a responsive e-commerce website built with HTML, CSS, and JavaScript.

## 🚀 Live Demo

[Visit Luma Store](https://lumastore.vercel.app/)

## ✨ Features

- Responsive design for desktop and mobile
- 24 products across 5 categories
- Product search functionality
- Shop All Products page
- Category-based product pages
- Add to Cart functionality
- Cart quantity controls
- Remove products from cart
- Clear cart functionality
- LocalStorage for saving cart data
- Checkout interaction
- Responsive navigation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git & GitHub
- Vercel

## 📂 Categories

- Clothing
- Shoes
- Accessories
- Beauty
- Electronics
